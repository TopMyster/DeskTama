# DeskTama

A Tamagotchi for your desktop

This is a Tamagotchi that can live on your desktop. It eats, plays, gains weight, and grows! Unfortunately, it can also die.

### How to use 
- Press the left button to feed your tama
- Press the middle button to play with it
- Press the right button to check its stats
- When tama gets hungry or unhappy, it will alert you with a sound effect
- When you press the middle button, You have to guess whether the number is greater or less than the previous number by pressing the left button for less and right button for greater. If you guess correctly, your tama will do a happy dance and gain a happy point, if you guess incorrectly, your tama will be sad.


### Installation
```bash
1. Clone the repository
   git clone https://github.com/TopMyster/DeskTama
   
2. Navigate to the project directory
   cd DeskTama

3. Install dependencies
   npm install

4. Run the application
   npm run dev
```
